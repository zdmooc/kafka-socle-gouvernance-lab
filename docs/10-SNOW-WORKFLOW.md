# Workflow projet (type SNOW)

## 1) Prise en charge ticket
- Qualification : type (incident / demande / change / problem)
- Priorité / SLA
- Collecte infos (logs, dashboards, reproduction)

## 2) Cadrage / conception / impact
- Analyse d’impact : topics, ACL, schémas, connect, perf, DR
- Rédaction SFD/STD si besoin
- Plan de test : TU, TI, non-régression

## 3) Devis & planning
- Abaque / UO négociées
- Date de livraison dans le devis
- Jalons et critères de Go/No-Go

## 4) Réalisation
- Dev / paramétrage
- Revue (pair + sécurité)
- Automatisation CI/CD si applicable

## 5) Tests
- TU + assistance recette
- Jeux de données (si besoin)
- TI + non-régression
- Evidence (captures/export)

## 6) Documentation & MEX
- MEX (what/why/how, runbooks, rollback)
- Base de connaissance + checklists

## 7) Réversibilité
- Documentation + passation + shadowing
- Inventaire : clusters, topics, users, dashboards, runbooks, accès
