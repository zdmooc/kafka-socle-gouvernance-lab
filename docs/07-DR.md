# Disaster Recovery (DR)

## Objectifs
- RPO/RTO par criticité
- Réplication asynchrone de topics critiques
- Procédure de bascule testée

## Option 1 : MirrorMaker2 (Strimzi)
- Un MM2 par sens si actif/actif
- ACLs dédiées pour MM2
- Filtrage topics (liste/pattern)

Manifests : `platform/kafka/mirrormaker2/*`

## Tests DR (périodiques)
- Drill : simuler indispo cluster primaire
- Vérifier : continuité flux critiques, latence réplication, backlog
- Post-mortem : MEX + actions

## Sauvegardes
- Configs topics/users (manifests git)
- Registry (si utilisé) : backup DB + export schemas
